# 补充实验论文结果表

数据集中在一个文件：[supplementary_experiment_results.csv](./supplementary_experiment_results.csv)。文件按实验纵向分区，每区使用自身的指标表头，最多8列；用Excel打开CSV即可在一张工作表中阅读全部结果。

精度与消融合并在同一区域，每个数据集、方法只出现一行；方法名称后标明消融对象或验证目的，评测设置区分源域测试、冻结迁移和目标监督OOF。

精度区每个指标采用“**单模型均值 ± 标准差 / 三模型预测平均**”。例如Full的 `0.740 ± 0.022 / 0.638`：左侧先对三个独立seed的Full分别评估再平均；右侧将三个Full对同一图像的预测平均，再计算指标。其余分区为单模型的三seed均值±SD。

常规精度、消融、OOF及投影残差均取六条件总体。仅Figure 3条件曲线和SyncG完整模型路由随条件变化保留六条件明细；透视曲线保留各扫描角度。

三模型集成使用三个独立训练模型；“三专家等权混合”是在单个模型内部给基础、极坐标、关系专家各1/3权重。集成结果没有三seed标准差。参数量与延迟区测量的是单个模型，不能作为三模型集成的部署成本；集成延迟未测量。

## 指标和单位

- NMAE为平均绝对误差除以满量程，RMSE为均方根误差除以满量程，均以%FS表示。
- Acc@1%、Acc@2%、Acc@5%为误差不超过对应满量程比例的记录占比，单位为%。
- 六条件总体先在每个seed内汇总完整记录，再跨seed求均值与标准差；RMSE从平方误差计算，不直接平均六个条件的RMSE。六条件不作为六倍独立采集样本。
- 路由权重与归一化熵使用0到1尺度，集中度列以%表示；投影残差使用归一化读数尺度，最大值列为各seed最大绝对残差的均值±SD。
- P50/P95是各seed延迟分位数的均值±SD。batch size=1，每seed使用32个预载解码ROI、5次重复；包含SARN、ROI缩放归一化、数据传输与完整读数推理，排除解码、检测与ROI提取。参数量为实际参与模块的独立参数，共享编码器计一次。
- 本批准确率表覆盖率均为100%；效率测量失败调用均为0。

## 方法

- GeoPRR完整模型：E14：独立初始化的完整模型，作为消融参照。源方法名 `full`。
- 仅几何/基础专家：E27：仅基础候选，检验专家融合的增益。源方法名 `base_only`。
- 简单双视图回归：E27：简单双视图对照，检验复杂读数结构的必要性。源方法名 `dual_view`。
- 仅极坐标专家：专家诊断：完整模型的极坐标候选单独读数。源方法名 `polar_only`。
- 仅关系专家：专家诊断：完整模型的关系候选单独读数。源方法名 `relational_only`。
- 去几何融合：移除几何融合，检验几何信息的贡献。源方法名 `no_geometry_fusion`。
- 去几何融合+固定路由：同时移除几何融合与自适应路由，检验两者交互。源方法名 `no_geometry_fixed_routing`。
- 去关系传输：移除关系传输，检验关系模块的贡献。源方法名 `no_relational_transport`。
- 去极坐标证据：移除极坐标证据，检验极坐标分支的贡献。源方法名 `no_polar_evidence`。
- 线性增益头：E20：检验末端增益映射中非线性的必要性。源方法名 `linear_gate`。
- 11标量MLP门控：E20：仅用11标量，检验高维输入的必要性。源方法名 `scalar_gate`。
- 三专家等权混合：E20：取消自适应路由，三个专家各占1/3。源方法名 `uniform`。
- 固定先验混合：E20：取消自适应路由，固定权重0.50/0.25/0.25。源方法名 `fixed_prior`。
- Raw B0（六条件增强）：C4：控制六条件训练增强覆盖的影响。源方法名 `raw_efficientnet_b0_six_condition`。
- Raw B0（原检查点）：原检查点的透视角度扫描对照。源方法名 `raw_efficientnet_b0`。
- GeoPRR目标监督OOF：C13：检验使用目标域标签的五折OOF适配。源方法名 `geoprr_oof`。

基础专家读取完整模型的基础候选；简单双视图回归为单独拟合的控制头。“GeoPRR目标监督OOF”及对应集成结果使用目标域标签，属于目标监督适配；其他准确率结果为源域训练后的固定模型评测。Figure 3角度扫描的Raw B0为原检查点，C4与六条件曲线中的Raw B0为六条件增强匹配模型。
